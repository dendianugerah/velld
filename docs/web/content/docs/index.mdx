Velld backs up PostgreSQL, MySQL, and MongoDB to local disk and optionally to S3-compatible storage or Cloudflare R2.

1. [Install Velld](/docs/installation), or [paste the install prompt into your agent](/docs/installation#install-with-your-agent).
2. [Add a database connection](/docs/databases) and [run your first backup](/docs/quick-start).
3. [Verify a restore or practice recovery](/docs/restore-best-practices) before relying on a backup.
