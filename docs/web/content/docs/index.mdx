Velld is a self-hosted, open-source tool for managing database backups. Connect your databases, schedule backups, and keep track of them from one place.

## Get started

1. [Install Velld](/docs/installation) on your server.
2. Follow the [quick start](/docs/quick-start) to connect a database and create your first backup.
3. Read the [restore best practices](/docs/restore-best-practices) to prepare for recovery.

## Supported databases

Velld supports PostgreSQL, MySQL, MariaDB, and MongoDB.

## How it works

1. **Connect** your database and test the connection.
2. **Back up** on demand or set a schedule and retention policy.
3. **Monitor** backup history and receive notifications when scheduled backups fail.
4. **Restore** using your backup files and the appropriate database tools.

Credentials are encrypted, and Velld also provides a REST API for managing backups.
